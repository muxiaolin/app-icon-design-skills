# HarmonyOS NEXT 图标规范

> 来源：Huawei Developer — Application Icon 设计规范（最后更新 2026-01-28）。核实日期：2026-09-11。

## 设计原则

三原则：**Elegantly simple**（雅致简约）、**Instantly recognizable**（一眼可辨）、**Emotionally engaging**（情感共鸣）。

## 图形与风格

- 整体采用**新拟态（neumorphism）**手法：半透明模糊 + 分层设计，呈现轻盈通透感；加强图标边缘高光，突出质感与清晰度。
- 图标以**单一主导元素**呈现应用用途与功能的隐喻图形；线条流畅、比例规整、配色考究。
- 网格布局：标准网格作为体量参考，图形元素占比要足够大，达成光学平衡与视觉重量一致；部分图形可按视觉体感突破网格。

## 色彩

- 背景光源自上而下：颜色**由浅到深**纵向渐变（顶部受光）。
- 渐变保持克制，**避免强对比渐变**（推荐柔和渐变，不推荐剧烈渐变）。

## 多设备适配（同一双层资源，默认风格不同）

| 设备 | 默认风格 | 要点 |
| --- | --- | --- |
| 手机 / 折叠屏 / 平板 | 平面风格 | 干净平面视觉语言，前后景对比清晰，避免过度复杂；主屏用应用主题色强化前景 |
| PC | 轻量 3D | 在平面基础上引入半透明材质、精细光照、清晰三层立体感；dock 悬停时系统在前景层下生成随光标动态阴影 + 点状漫射高光 + 柔光 |
| Vision | 轻量 3D | 柔和阴影 + 鲜艳色彩，衬深色沉浸背景；launcher 支持追光效果 |
| 穿戴 | 平面 | 圆形容器；前景水平垂直居中、留足 padding 防裁切、在圆形蒙版内保持主导地位 |

## 资源硬性规范（上架校验）

- 图标资源必须**分层**（前景层 + 背景层）。
- 尺寸 **1024×1024 px**，正方形 PNG。
- **不需要圆角**——系统按场景自动生成蒙版裁切。
- **背景层不得含任何透明像素**（圆角或内部透明 padding 造成的也算违规）。

| 平台 | 层数 | 形状 | 尺寸 | 格式 |
| --- | --- | --- | --- | --- |
| 手机 / 折叠屏 / 平板 | 双层 | 方形 | 1024×1024 px | PNG |
| PC | 双层 | 方形 | 1024×1024 px | PNG |
| Vision | 双层 | 方形 | 1024×1024 px | PNG |
| 穿戴 | 单层 | 圆形 | 152×152 px | PNG |

资源放入 HAP 包后需通过发布检查。

## 模板

官方提供 HarmonyOS AppIcon Design (.zip) 模板（华为开发者文档页内下载链接），配套 Typography 与 HarmonyOS Symbol 规范。

## 元服务图标（区分项）

元服务图标与应用图标有明显区别：内部圆形表示完整独立，外圈装饰线表示"可分可合可流转"——不要把元服务图标做成普通应用图标的样式。
